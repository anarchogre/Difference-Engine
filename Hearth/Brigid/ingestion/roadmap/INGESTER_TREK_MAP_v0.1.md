## Immediate Route

### Phase 1 — Real Conversation Recovery

1. Select one Linux-heavy Difference Engine conversation.
2. Generate immutable receipt.
3. Preserve exact source.
4. Recover conversation metadata.
5. Recover complete message boundaries.
6. Recover speakers and message order.
7. Recover code fences.
8. Recover shell command blocks.
9. Recover inline commands.
10. Recover paths, filenames, URLs, and attachments.
11. Preserve exact source offsets.
12. Validate deterministic output.

### Phase 2 — Typed Recovery

Recover without interpretation:

- observations
- decisions
- reversals
- questions
- implementation steps
- failures
- corrections
- queues
- blockers
- governance statements
- specifications
- artifacts
- relationships
- supersession

### Phase 3 — Evidence Graph

Link every recovered object to:

- source artifact
- source message
- speaker
- message order
- extraction operation
- parent object
- related objects

### Phase 4 — Governed Classification

Route recovered objects to:

- evidence
- observation
- queue
- candidate doctrine
- candidate specification
- implementation record
- validation record
- unresolved state
- rejection
- deferral

No autonomous canonical promotion.

### Phase 5 — Acceptance Test

Ingest one complete Linux-heavy conversation and produce:

- complete preserved source
- turn graph
- command corpus
- Linux guidance candidates
- implementation history
- decisions and reversals
- queue candidates
- provenance graph
- deterministic output package
- restartable state
- human review package

## Constraints

- Recovery before interpretation.
- No summarization as ingestion.
- No silent promotion.
- No source mutation.
- No skipped messages.
- No lost ordering.
- No architecture beyond recovered evidence.
- One failing primitive at a time.
