# STARTUP_PROCEDURE v1.0

## Purpose
Defines the standard operator workflow for starting a new ADE engineering session.

## Prompt 1
Read the uploaded documents completely and in order. Do not summarize. Do not redesign. Acknowledge readiness and wait.

## Prompt 2
Use the connected GitHub repository 'anarchogre/ADE-Working-Repository-' as the authoritative operational corpus. Verify GitHub, CoGo, and repository access. If verification fails, report the exact issue and stop.

## Prompt 3
Begin Repository Archaeology Pass 1. Inspect before proposing. Classify before creating. Preserve provenance. Generate Markdown artifacts as milestones complete.

## Expected First Deliverable
Repository_Census_v0.1.md

## Engineering Principles
- Repository First
- Evidence First
- Markdown First
- Execution Before Refinement
- Constitution Before Bootstrap
- Bootstrap Before Conversation
- Repository Before Memory

## Definition of Success
Read Governance → Verify GitHub → Verify CoGo → Access Repository → Repository Census → Classification → Markdown Artifacts → Continue Engineering
