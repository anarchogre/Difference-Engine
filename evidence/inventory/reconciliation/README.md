# Mission 000 Evidence Repository

This directory contains the evidence and provenance generated during the
reconciliation of legacy ADE repositories and the bootstrap of the
DifferenceEngine repository.

## Structure

manifests/
    File inventories and normalized manifests.

diffs/
    Repository comparisons.

hashes/
    SHA-256 and integrity reports.

reports/
    Human-readable findings and analysis.

snapshots/
    Point-in-time filesystem captures.

logs/
    Session markers and operational logs.

## Method

Observe
→ Preserve
→ Classify
→ Corroborate
→ Curate
→ Build
→ Retire

No destructive operations are performed until evidence supports them.
