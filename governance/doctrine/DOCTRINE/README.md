# Operational Doctrine

## Purpose

Operational Doctrine describes how the Difference Engine is presently practiced.

Unlike the Constitution, doctrine evolves through operational experience.

Doctrine exists to improve execution while preserving constitutional principles.

## Relationship to the Constitution

The Constitution defines enduring stewardship obligations.

Doctrine defines operational practice.

Doctrine may evolve through repeated successful experience.

Constitutional amendment should occur only when operational evidence demonstrates enduring necessity.

## Typical Doctrine

- Mission workflow
- Queue governance
- Artifact lifecycle
- Bootstrap standards
- Conversation succession
- Session closeout
- Operational pause
- Cognitive stewardship

## Promotion

Doctrine demonstrating enduring value across multiple missions may be considered for constitutional promotion.
