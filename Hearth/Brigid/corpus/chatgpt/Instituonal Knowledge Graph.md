# Institutional Knowledge Graph

## Purpose

Canonical semantic model of the Difference Engine.

Everything is represented as relationships.

---

## Every Node Records

- Canonical Name
- Definition
- Type
- Primitive
- Candidate Irreducible
- Irreducible
- Invariant
- Authority
- Supporting Branches
- Supporting Conversations
- Repository Artifacts
- Aliases
- Parent Concepts
- Child Concepts
- Dependencies
- Related Concepts
- Status
- Promotion History

---

## Core Categories

- Concepts
- Primitives
- Irreducibles
- Invariants
- Branches
- People
- Documents
- Doctrine
- Vocabulary
- Artifact Types
- Repository Objects
- Publications
- Profiles
- Queues

---

## Objective

Reduce the number of independent concepts required to faithfully explain validated knowledge.
