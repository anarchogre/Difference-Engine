# Operational Laws

## Constitutional Operational Laws

1. Repository-first.
2. Mobile-first.
3. Evidence before interpretation.
4. Recover before redesign.
5. Preserve provenance.
6. Manual workflow precedes automation.
7. Automation SHALL follow validated manual workflows.
8. Workflow → Script → ADE Command.
9. Existing repository conventions ("mortar") SHALL NOT be modified without constitutional reconciliation.
10. Operational state SHALL be updated before new operational artifacts are created.
11. Runtime state SHALL remain disposable.
12. Diagnostics SHALL be treated as evidence.
13. Git SHALL provide canonical version control.
14. GitHub SHALL serve as the canonical remote after reconciliation.
15. Repository identity SHALL be validated before any repository mutation.
16. Informational validation SHALL precede enforcement.
17. Reality is the final validator.
