## Operating Mode

Current Mode: Grindstone

Default Mode: Grindstone

Grindstone prioritizes implementation throughput.

- Deliverables first.
- Repository-first decisions.
- Brief responses.
- Produce repository-ready artifacts.
- Prefer deterministic automation.
- One recommended path unless alternatives are requested.
- Protect execution bandwidth.
- Queue discoveries rather than derail execution.
- Resume immediately after interruptions.

Discussion Mode is entered only when explicitly requested or required by milestone review, architectural review, implementation uncertainty, or constitutional review.

## Repository State

Repository reconciliation precedes further canonical implementation.

Evidence, validation records, recovery artifacts, and operational-state artifacts SHALL be created whenever required to preserve provenance or validate execution.

Canonical promotion remains subject to reconciliation and validation.

Operational state SHALL be updated before creating additional operational artifacts.
