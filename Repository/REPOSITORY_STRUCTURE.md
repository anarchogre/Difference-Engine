# Repository Structure

## Top-Level Layout

``` text
ADE/
├── README.md
├── INDEX.md
├── CHANGELOG.md
├── ROADMAP.md
├── GLOSSARY.md
├── REPOSITORY_CHARTER.md
├── REPOSITORY_STRUCTURE.md
├── RC/
├── PP/
├── Library/
├── Handbook/
├── Governance/
├── Specifications/
├── Parser/
├── Archive/
└── Tools/
```

## Document Series

-   RC --- Repository Constitution
-   PP --- Preservation Points
-   OBS --- Observation Database
-   SPEC --- Specifications
-   GOV --- Governance
-   REF --- Reference Material

Additional series should follow the same stable naming conventions.
