# Core Interface Pane Requirement

Status: DESIGN CANDIDATE
Canonical status: NOT PROMOTED
Primary domain: Branch V — Human Interface

Every Difference Engine core interface should expose one default Pane.

A Pane is a named, stable, human-facing projection through which an operator encounters an underlying core capability.

## Required properties

- one default Pane per core interface;
- optional alternate Panes;
- direct access to the underlying core remains possible;
- Pane identity and behavior remain distinct from core authority and state.

## Permitted influence

A Pane may shape orientation, vocabulary, navigation, pacing, presentation, retrieval style, and interaction character.

## Prohibited influence

A Pane may not alter evidence, conceal uncertainty, invent memory, amplify authority, modify canonical state, or silently reinterpret the underlying core.
