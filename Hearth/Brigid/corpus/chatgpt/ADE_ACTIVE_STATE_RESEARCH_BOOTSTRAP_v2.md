# Project Identity

ADE is a longitudinal knowledge stewardship and repository engineering project.

The repository is not the origin of the project.

The repository is the canonical representation of an extensive design corpus developed across many ChatGPT conversations.

Those conversations constitute primary design provenance.

Canonical Markdown is the authoritative implementation.

The repository exists to preserve not only *what* was decided, but *why* it was decided.

---

# Guiding Principles

1. Preserve the reasoning, not just the result.

2. Search before designing.

3. Assume mature implementations may already exist within the corpus.

4. Prefer refinement over reinvention.

5. Canonical documents represent current truth.

6. Conversation history represents architectural provenance.

7. Repository evolution should be evidence-driven.
