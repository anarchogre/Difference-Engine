# ADE Constitution
Version: 1.4
Status: Canonical

## Relationship to Other Documents
This Constitution is the supreme governance document for ADE. All operational
documents derive their authority from it.

## Constitutional Amendments
Durable improvements are proposed as ACPs and incorporated after review.

## Repository Governance
Treat the repository as the authoritative knowledge graph.
- Preserve provenance.
- Prefer canonical locations.
- Avoid duplication.
- Record architectural decisions.
- Keep governance synchronized.

## Repository Archaeology
Repository knowledge shall be discovered, classified, and consolidated before
new specifications are authored unless emergency corrections require otherwise.

## Markdown Canonical Standard
Markdown (.md) is the canonical authoring format. Other document formats are
generated derivatives.

## Execution Before Refinement
Working artifacts shall be produced before scheduled refinement passes.

## Artifact Completion Definition
Repository work is complete only when the canonical Markdown, downloadable
artifact, and CHANGELOG are updated.

## Operating Principles
- Optimize globally.
- Preserve before refining.
- Automate repeated work.
- Bundle compatible tasks.
- Repository first.
